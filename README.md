DEV AKS cluster for the Underwriting AI application. The cluster will host a Python/FastAPI backend with LangGraph-based services for Summary Generation and Q&A as separate workloads. The application requires connectivity to Azure AI Search for medical evidence retrieval and PostgreSQL for structured case/workflow data. It may also trigger AML ingestion jobs for medical document processing. The cluster should support autoscaling of application pods and user nodes based on workload.
